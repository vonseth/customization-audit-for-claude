06 — Glossary06 — Begriffe

What the words meanWas die Wörter bedeuten
CustomizationAnpassung
Umbrella term for everything that extends Claude: plugins, skills, MCP servers.Sammelbegriff für alles, was Claude erweitert: Plugins, Skills, MCP-Server.
Plugin
Package of skills, commands, agents, hooks or MCP servers.Paket aus Skills, Befehlen, Agents, Hooks oder MCP-Servern.
Desktop pluginDesktop-Plugin
Installed in the Claude app (Customize → Plugins).In der Claude-App installiert (Customize → Plugins).
Local pluginLokales Plugin
Installed through Claude Code; lives in ~/.claude/plugins.Über Claude Code installiert; liegt in ~/.claude/plugins.
Own skillEigener Skill
A skill without a plugin in ~/.claude/skills.Skill ohne Plugin in ~/.claude/skills.
MarketplaceMarktplatz
A source plugins are installed from.Quelle, aus der Plugins installiert werden.
Own marketplaceEigener Marktplatz
Your own repository that is also the marketplace of the plugin it contains.Dein eigenes Repository, das zugleich der Marktplatz des enthaltenen Plugins ist.
claude.ai skillclaude.ai-Skill
Managed on claude.ai under Customize → Skills; also appears in the desktop app and in code sessions.In claude.ai unter Customize → Skills verwaltet; erscheint auch in der Desktop-App und in Code-Sitzungen.
Built-inEingebaut
Comes with Claude Code (identifier @builtin); not installed by you, not part of the audit.Kommt mit Claude Code (Kennung @builtin); nicht von dir installiert, nicht Teil des Audits.
CandidateKandidat
A customization you named but have not installed; researched only, to be reviewed before installing.Von dir genannte, noch nicht installierte Anpassung; nur recherchiert, vor einer Installation zu prüfen.
MCP serverMCP-Server
Interface (Model Context Protocol) through which Claude uses the tools of a service.Schnittstelle (Model Context Protocol), über die Claude Werkzeuge eines Dienstes nutzt.
Connector
An MCP server from claude.ai; independent of a plugin with the same name.MCP-Server aus claude.ai; unabhängig von einem gleichnamigen Plugin.
Plugin MCPPlugin-MCP
An MCP server that a plugin brings along; it only goes away with the plugin. “Not signed in” means: not usable.MCP-Server, den ein Plugin mitbringt; entfällt nur mit dem Plugin. „Nicht angemeldet“ heißt: nicht benutzbar.
ExtensionErweiterung
Desktop extension of the Claude app with its own MCP server.Desktop-Erweiterung der Claude-App mit eigenem MCP-Server.
Hook
A script that Claude Code runs automatically on an event, for example at every session start; relevant for security.Skript, das Claude Code bei einem Ereignis automatisch ausführt, z. B. bei jedem Sitzungsstart; sicherheitsrelevant.
Auto-start blockedSelbststart gesperrt
A skill with disable-model-invocation: it only starts when you call it with /name.Skill mit disable-model-invocation: startet nur auf Aufruf mit /name.
FindingBefund
A numbered single result of a partial report.Nummerierter Einzelbefund eines Teilberichts.
Tokens
Permanent cost per session caused by the descriptions (characters ÷ 3.7, estimated); the content is added when a customization is called.Dauerkosten je Sitzung durch die Beschreibungen (Zeichen ÷ 3,7, geschätzt); bei Aufruf kommt der Inhalt hinzu.
Permanent contextDauerkontext
What Claude reads at the start of every session about your customizations (short descriptions, tool names, instructions). It costs tokens whether you use them or not.Was Claude zu Beginn jeder Sitzung über deine Anpassungen liest (Kurzbeschreibungen, Werkzeugnamen, Anweisungen). Es kostet Tokens, ob du sie nutzt oder nicht.
Core / complement / replaceableKern / Ergänzung / ersetzbar
The roles in an overlap topic: the one with most value, one that adds a different job, one that another item already covers.Die Rollen in einem Überschneidungsthema: was den größten Wert hat, was eine andere Aufgabe ergänzt, was ein anderer Eintrag schon abdeckt.
UniquenessEinzigartigkeit
A rating of one to five dots for how much a customization does that no other one here does.Eine Bewertung von einem bis fünf Punkten dafür, wie viel eine Anpassung leistet, was keine andere hier leistet.
Quality gateQualitätsprüfung
The independent check at the end of an audit: a separate agent compares the report with the raw data.Die unabhängige Prüfung am Ende eines Audits: Ein eigener Agent vergleicht den Bericht mit den Rohdaten.
Sub-agentSub-Agent
A helper agent Claude starts for one part of the audit, with the smallest model that fits the work.Ein Hilfsagent, den Claude für einen Teil des Audits startet, mit dem kleinsten Modell, das zur Arbeit passt.
BackupSicherung
A copy of what is about to change, in ~/.claude/backups/<reason>-<date>/, made before every change with backup.py.Eine Kopie dessen, was sich ändern soll, in ~/.claude/backups/<Anlass>-<Datum>/, vor jeder Änderung mit backup.py angelegt.
ManifestManifest
The file manifest.json in a backup folder: original path, stored copy, type, checksum and size of every item. Restore uses it; older backups have none.Die Datei manifest.json in einem Sicherungsordner: Originalpfad, gespeicherte Kopie, Art, Prüfsumme und Größe jedes Eintrags. Die Wiederherstellung nutzt sie; ältere Sicherungen haben keine.
SnapshotMomentaufnahme
One entry in the history of your audits: date, permanent tokens, installed, removed and candidates. Stored by history.py at the end of an audit.Ein Eintrag im Verlauf deiner Audits: Datum, Dauer-Tokens, installiert, entfernt und Kandidaten. history.py speichert ihn am Ende eines Audits.
DeferredZurückgestellt
Tools that are not loaded at the start of a session but only when needed. They cost no permanent context until used; /context reports them separately.Werkzeuge, die nicht zu Beginn einer Sitzung geladen werden, sondern erst bei Bedarf. Sie kosten bis zur Nutzung keinen Dauerkontext; /context weist sie getrennt aus.
Schema versionSchemaversion
The data format of the page data, stored as schema_version in the block data-meta. A missing value means schema 0 (data from versions before 1.4.0). Update, import and migrate bring the data to the format the tools expect.Das Datenformat der Seitendaten, gespeichert als schema_version im Block data-meta. Ein fehlender Wert bedeutet Schema 0 (Daten aus Versionen vor 1.4.0). Update, Import und migrate bringen die Daten in das Format, das die Werkzeuge erwarten.
Managed filesVerwaltete Dateien
The files an update replaces: the tool, test, asset, documentation and example folders, the top-level project files and the rules part of CLAUDE.md. Your reports, page data and USER sections are not managed.Die Dateien, die ein Update ersetzt: die Ordner für Werkzeuge, Tests, Assets, Dokumentation und Beispiele, die Projektdateien der obersten Ebene und der Regelteil der CLAUDE.md. Deine Berichte, Seitendaten und USER-Abschnitte gehören nicht dazu.
USER markersUSER-Markierungen
The lines <!-- USER:START name --> and <!-- USER:END name --> in CLAUDE.md. What stands between them is yours; an update carries it over unchanged. Text outside the markers is replaced.Die Zeilen <!-- USER:START name --> und <!-- USER:END name --> in der CLAUDE.md. Was dazwischen steht, gehört dir; ein Update übernimmt es unverändert. Text außerhalb der Markierungen wird ersetzt.
Data blockDatenblock
The JSON text at the end of audit-overview.html that holds your data; the visible page is built from it.Der JSON-Text am Ende der audit-overview.html, der deine Daten enthält; die sichtbare Seite wird daraus gebaut.
Sample dataBeispieldaten
Fictional entries that fill the page so you can see how an audit looks; removable.Erfundene Einträge, die die Seite füllen, damit du siehst, wie ein Audit aussieht; entfernbar.

07 — Usage07 — Verwendung

How do I use the audit?Wie verwende ich das Audit?

The audit keeps your Claude customizations lean and safe. You need no technical knowledge: open a session in this project folder in the Claude app and say in your own words what you want. Claude explains first, asks next and changes something only after your yes; before that it makes a backup.Das Audit hält deine Claude-Anpassungen schlank und sicher. Technik brauchst du dafür nicht: Öffne in der Claude-App eine Sitzung in diesem Projektordner und sag in eigenen Worten, was du möchtest. Claude erklärt zuerst, fragt dann und ändert erst nach deinem Ja; vorher legt es eine Sicherung an.

Get an overviewÜberblick verschaffen
Open this page, also on a phone in the Files app. The key figures are at the top; an entry in the list opens when you tap it and shows details and the recommendation.Öffne diese Seite, auch auf dem iPhone in der App Dateien. Oben stehen die Kennzahlen; ein Eintrag in der Liste klappt beim Antippen auf und zeigt Einzelheiten und Empfehlung.
Review everything againAlles neu prüfen
For example every few months. Say: “Run the audit following docs/review-guide.md.” Claude records what is installed, checks security, usage and new versions, and then goes through each point with you.Zum Beispiel alle paar Monate. Sag: „Führe das Audit nach docs/review-guide.md durch.“ Claude erfasst den Bestand, prüft Sicherheit, Nutzung und neue Versionen und bespricht danach jeden Punkt einzeln mit dir.
Install something newEtwas Neues installieren
Say: “I want to install the plugin XY, please check it” and add the link. Claude explains benefit, cost and risks and gives a recommendation. Only after your yes do the security check and the installation follow.Sag: „Ich möchte das Plugin XY installieren, prüfe das bitte“ und füge den Link an. Claude erklärt Nutzen, Kosten und Risiken und gibt eine Empfehlung. Erst nach deinem Ja folgen Sicherheitsprüfung und Installation.
Get rid of somethingEtwas loswerden
Say: “Do I still need XY?” Claude shows what it is for and what goes away. After your yes it is removed and entered under “Removed”. Plugins of the Claude app you remove there yourself; Claude tells you where.Sag: „Brauche ich XY noch?“ Claude zeigt, wofür es da ist und was wegfällt. Nach deinem Ja wird es entfernt und unter „Entfernt“ eingetragen. Plugins aus der Claude-App entfernst du dort selbst; Claude sagt dir, wo.
Check for new versionsAuf neue Versionen prüfen
Say: “Are there new versions of my customizations?” Claude checks local plugins offline (python3 -I tools/check_versions.py), looks at the rest separately, names what changed and updates only when you ask. “Unknown” means the tool cannot tell, not that something is outdated.Sag: „Gibt es neue Versionen meiner Anpassungen?“ Claude prüft lokale Plugins ohne Netz (python3 -I tools/check_versions.py), schaut sich den Rest getrennt an, nennt, was sich geändert hat, und aktualisiert nur auf deinen Wunsch. „Unbekannt“ heißt: Das Werkzeug kann es nicht beurteilen, nicht dass etwas veraltet ist.
See what changed since the last auditÄnderungen seit dem letzten Audit sehen
Say: “What changed since the last audit?” or run python3 -I tools/diff_inventory.py. It lists what is new, gone, changed in status or noticeably different in token cost. Nothing is written.Sag: „Was hat sich seit dem letzten Audit geändert?“ oder führe python3 -I tools/diff_inventory.py aus. Es zeigt, was neu, weggefallen, im Status geändert oder bei den Token-Kosten deutlich anders ist. Geschrieben wird nichts.
Measure MCP costMCP-Kosten messen
Open a new Claude Code session, type /context, expand “MCP tools”, copy the text and paste it to Claude. Claude never runs /context itself; it measures your text with tools/mcp_cost.py. The page then shows the permanent cost and, per server, the size of all its tools.Öffne eine neue Claude-Code-Sitzung, gib /context ein, klappe „MCP-Tools“ auf, kopiere den Text und füge ihn bei Claude ein. /context führt Claude nie selbst aus; es misst deinen Text mit tools/mcp_cost.py. Die Seite zeigt danach die Dauerkosten und je Server die Größe aller seiner Werkzeuge.
Add a candidateKandidaten aufnehmen
Something you might want later but have never installed: say “Add the connector XY as a candidate” and add the link. Claude looks up what it is, what it costs and what it overlaps with, and lists it under “Not installed yet”. Nothing is installed. When you discuss it later you decide: install, keep it on the list or move it to “Removed” with a reason.Etwas, das du vielleicht später willst, aber nie installiert hast: Sag „Nimm den Connector XY als Kandidaten auf“ und füge den Link an. Claude ermittelt, was es ist, was es kostet und womit es sich überschneidet, und führt es unter „Noch nicht installiert“. Installiert wird nichts. Bei der späteren Besprechung entscheidest du: installieren, auf der Liste lassen oder mit Grund unter „Entfernt“ ablegen.
Save your data (export)Daten sichern (Export)
Say “Export my audit data” or run python3 -I tools/import_data.py --export my-audit.json. The file holds everything on this page and is your backup. It contains your personal setup, so do not share it.Sag „Exportiere meine Audit-Daten“ oder führe python3 -I tools/import_data.py --export my-audit.json aus. Die Datei enthält alles von dieser Seite und ist deine Sicherung. Sie zeigt deine persönliche Einrichtung, gib sie also nicht weiter.
Bring your data along (import)Daten übernehmen (Import)
In a fresh or newer download, run python3 -I tools/import_data.py my-audit.json. Your entries, decisions and token figures come back and you do not need a first review. If the page already holds data, add --replace.Führe in einem frischen oder neueren Download python3 -I tools/import_data.py my-audit.json aus. Deine Einträge, Entscheidungen und Token-Zahlen sind wieder da, eine erste Besprechung entfällt. Enthält die Seite schon Daten, hänge --replace an.
Store a snapshot (history)Momentaufnahme speichern (Verlauf)
At the end of an audit say “Store a snapshot” or run python3 -I tools/history.py snapshot. It keeps date, tokens and counts. From two snapshots on the token card shows a timeline.Sag am Ende eines Audits „Speichere eine Momentaufnahme“ oder führe python3 -I tools/history.py snapshot aus. Es merkt sich Datum, Tokens und Anzahlen. Ab zwei Einträgen zeigt die Token-Karte einen Verlauf.
Back up and restoreSichern und wiederherstellen
Before every change Claude runs python3 -I tools/backup.py create and saves to ~/.claude/backups/. To undo, say “Restore the backup XY”: Claude shows what would be overwritten and you confirm with “y”. Nothing is restored without that.Vor jeder Änderung führt Claude python3 -I tools/backup.py create aus und sichert nach ~/.claude/backups/. Zum Zurücknehmen sag „Spiele die Sicherung XY zurück“: Claude zeigt, was überschrieben würde, und du bestätigst mit „y“. Ohne das wird nichts zurückgespielt.
Update to a new versionAuf eine neue Version aktualisieren
Copies of version 1.3.0 or older do not contain update.py yet: for the first move to 1.4.0, download 1.4.0 and use the manual path once (export, import, copy reports/ and your CLAUDE.md decisions by hand); from 1.4.0 on, update.py does this for you. Say “Is there a new version of the project?” or run python3 -I tools/update.py check. To update, say “Update the project” (update.py apply): you see a preview and confirm, a full backup is made first, your data and your own CLAUDE.md sections are kept, and a failed update is restored automatically. update.py rollback undoes the last update; it also reverts reports and data created since the update (a safety backup is made first). This is the only tool that uses the network (read-only, api.github.com).Kopien der Version 1.3.0 oder älter enthalten noch kein update.py: Für den ersten Wechsel auf 1.4.0 lädst du 1.4.0 herunter und gehst einmal den manuellen Weg (Export, Import, reports/ und deine CLAUDE.md-Entscheidungen von Hand kopieren); ab 1.4.0 übernimmt das update.py. Sag „Gibt es eine neue Version des Projekts?“ oder führe python3 -I tools/update.py check aus. Zum Aktualisieren sag „Aktualisiere das Projekt“ (update.py apply): Du siehst eine Vorschau und bestätigst, vorher wird eine vollständige Sicherung angelegt, deine Daten und deine eigenen Abschnitte in der CLAUDE.md bleiben erhalten, und ein fehlgeschlagenes Update wird automatisch zurückgespielt. update.py rollback nimmt das letzte Update zurück; dabei werden auch Berichte und Daten zurückgesetzt, die seit dem Update entstanden sind (vorher wird eine Sicherung angelegt). Es ist das einzige Werkzeug mit Netzzugriff (nur lesend, api.github.com).
Read what happenedNachlesen, was passiert ist
Every change is in the report with date and reason (section 05 — Documentation).Jede Änderung steht mit Datum und Grund im Bericht (Abschnitt 05 — Dokumentation).

About the “Usage” column: it counts how often a customization was called in the Claude app on this computer, up to the date of the last count. Use in the browser and in the phone app is not included. “0” means: no call in that time.Zur Spalte „Nutzung“: Gezählt ist, wie oft eine Anpassung in der Claude-App auf diesem Rechner aufgerufen wurde, bis zum Datum der letzten Zählung. Nutzung im Browser und in der Handy-App ist nicht enthalten. „0“ heißt: in dieser Zeit kein Aufruf.
